✨ 주요 기능

✍️

Text-to-Image

텍스트 설명만으로 고품질 이미지를 생성합니다. 상상한 것을 그대로 이미지로!

🔄

Image-to-Image

기존 이미지를 다른 스타일로 변환합니다. 사진을 유화나 애니메이션 스타일로!

🎨

8가지 스타일

Realistic, Anime, Oil Painting, Watercolor, Cyberpunk, Fantasy, Minimalist, Vintage

⚡

GPU 최적화

RTX 4050에 최적화되어 빠른 이미지 생성이 가능합니다.

웹 UI 제공

🔌 API 엔드포인트

Method Endpoint 설명
GET /health 서버 상태 확인
POST /generate Text-to-Image 생성
POST /img2img Image-to-Image 변환
GET /styles 스타일 프리셋 목록
GET /history 생성 기록 조회
GET /stats 통계 정보
GET /download/{id} 이미지 다운로드
DELETE /history/{id} 이미지 삭제

💻 사용 예시

# Python으로 이미지 생성하기 import requests response = requests.post( "http://localhost:8000/generate", json={ "prompt": "a beautiful sunset over the ocean", "style": "realistic", "steps": 50 } ) data = response.json() print(f"이미지 생성 완료! ID: {data['id']}")
